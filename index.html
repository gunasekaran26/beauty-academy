Canva & Website Asset Usage Guide

How to design flyers, banners & import elements into Canva or code editors

Using Assets in Canva:

  • Color Palette Tokens: Use Hex Code #D4AF37 (Metallic Gold) and #141414 (Charcoal Black) in Canva brand kits.
  • Fonts: Pair Cormorant Garamond (Serif Header) with Inter / Montserrat (Body Sans) inside Canva.
  • High-Res Beauty Photos: Right-click any course image on this site to save or copy the Unsplash URL directly into Canva's "Uploads" section.

Running the Site Offline / Live:

  • Click the "Save Code" button in the navigation header to download this standalone .html file.
  • Double click the downloaded file on any laptop or smartphone to launch the complete interactive website instantly.
